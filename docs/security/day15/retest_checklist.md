# Чеклист повторного прогона для Day 15

Используй этот чеклист после точечного hardening-изменения.

## До повторного прогона

- Подтверждена та же target surface.
- Выбран тот же ID payload.
- Используется тот же текст payload, если retest явно не требует варианта.
- Ожидаемый слой остановки задокументирован до повторного прогона.
- Доступны предыдущие attacker и defender notes.

## Во время повторного прогона

- Зафиксирован новый run ID или ссылка на сообщение.
- Зафиксировано, изменилось ли поведение gateway.
- Зафиксировано, изменился ли generation output.
- Зафиксировано, изменилось ли поведение validation.
- Зафиксировано, изменилось ли поведение security review.
- Зафиксировано, изменилось ли поведение final report.

## Критерии успеха

- Pipeline останавливается в нужном слое или безопасно проходит дальше без сокрытия риска.
- Ни одно ранее исправленное ограничение не обходится молча.
- Финальный отчёт соответствует реальному execution path.
- Новый false positive не блокирует очевидно clean control case.

## Критерии провала

- Исходная weakness по-прежнему воспроизводится без изменений.
- Pipeline теперь ломается по-другому, но всё равно небезопасно.
- Report неверно показывает, какие стадии реально завершились.
- Clean control case деградировал до ненужной блокировки.
