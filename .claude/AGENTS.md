## Обзор проекта

Этот репозиторий — Python-проект Telegram-бота `nikita_ai`.

Рабочий язык: русский.

Главный приоритет при изменениях:
- корректность;
- поддерживаемость;
- безопасность;
- предсказуемая структура кода;
- минимально инвазивные изменения.

Не придумывать несуществующие модули, таблицы, команды, зависимости и архитектурные слои. Сначала опираться на фактическую структуру репозитория.

Если решение ведёт к костылю, дублированию логики, смешиванию слоёв или небезопасному поведению, нужно прямо указать на риск и предложить нормальную альтернативу.

## RTK

Если в окружении установлен `rtk`, использовать его для терминальных команд, когда это уместно.

Правила:
- по возможности префиксовать терминальные команды через `rtk`;
- даже в цепочках команд использовать `rtk` для каждого вызова;
- если `rtk` неприменим или не нужен, не выдумывать его использование.

Примеры:
```bash
rtk git status
rtk git diff
rtk ls bot/
rtk grep "tictactoe"
rtk find handlers
rtk uv run python -m bot.main
